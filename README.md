##  About Me

<div align="center">
  <img align="right" alt="Coding GIF" width="300" src="https://media.giphy.com/media/SWoSkN6DxTszqIKEqv/giphy.gif" />

Hey there! I'm **Pankaj Maulekhi**, a passionate **AI & Data Science** undergraduate at **IIITDM Kurnool**.<br>

I enjoy building **intelligent systems**, deploying **machine learning models**, and solving real-world problems through code.<br>

My interests lie in **AI**, **Machine Learning**, **Deep Learning**, and **Generative AI** — from model development using **PyTorch**, **TensorFlow**, and **Hugging Face** to production deployment with **FastAPI**, **Docker**, and **AWS**.<br>

Lately I've been going deep on **generative modeling** (diffusion models, flow matching, GANs, VAEs) and **agentic LLM systems** — fine-tuning large diffusion transformers with QLoRA/DreamBooth on AWS SageMaker, and building multi-node **LangGraph** RAG pipelines on **AWS Bedrock**, evaluated with **Ragas**.

When I'm not coding, you'll find me experimenting with **MLOps pipelines** (MLflow, DVC, GitHub Actions), fine-tuning models, or picking up new tools to stay sharp.

## Currently Exploring

- 🎨 **Generative Modeling** — Diffusion models, flow matching & score matching, DDPM/DPM-Solver, consistency models, classifier-free guidance, DiT/adaLN-Zero, RoPE & MM-DiT architectures
- 🧬 **Diffusion Model Fine-Tuning** — DreamBooth-style QLoRA fine-tuning of FLUX.2 Klein 9B on AWS SageMaker (ml.g4dn.2xlarge), including a custom Alphonse Mucha style LoRA
- 🕸️ **Agentic AI & RAG** — LangGraph multi-node pipelines (retrieval decision, grounding, critic, judge nodes), RAG evaluation with Ragas, AWS Bedrock, LlamaIndex, Redis, Langfuse observability
- 🖼️ **GANs & VAEs** — CycleGAN, ProGAN, StyleGAN/StyleGAN2, WGAN-GP, VAEs with ELBO derivations
- 🤖 **LLM Pretraining & Alignment** — Built and published **PM-MiniFinLLM**, a 110M-parameter GPT-2-style finance LLM pretrained on ~2.36B tokens from SEC EDGAR, with SFT + DPO alignment
- 🧠 **RL & Transformer Internals** — RLHF (PPO, DPO, GRPO), RoPE, GQA/MQA, KV caching, quantization (GPTQ, AWQ, GGUF, bitsandbytes)
